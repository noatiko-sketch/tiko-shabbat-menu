# טיקו — GitHub Pages וגוגל בלבד

## בחירת האחסון

לפי בקשת נעה אין Vercel ואין אחסון Cloudflare חדש. הממשק הסטטי פועל ב־GitHub Pages. פעולות הנתונים פועלות באותו Google Apps Script ובאותו קובץ Drive. האתר הישן נשאר זמין עד אימות האתר החדש.

## חיבור הממשק

- pages/main.tsx טוען את אותו ממשק React, ללא שרת Next.js.
- הכתובת הציבורית של פריסת גוגל נמצאת ב־google/deployment.json וב־workflow. היא אינה סוד.
- lib/google-transport.ts מנהל חיבור postMessage למסגרת HTML Service של גוגל; google/Bridge.html מקבל רק הודעות מהמקור המוגדר, עם nonce אקראי. תשובות נקשרות לחלון ולמקור המדויקים שהשלימו את החיבור.
- google.script.run מפעיל את pagesRequest, שבודק כניסה ופרופיל משפחתי לפני כל קריאה או כתיבה. מפתח TIKO_BRIDGE_TOKEN נשאר בשרת הישן ובגוגל ואינו מגיע לדפדפן או ל־GitHub Pages.
- תפריט וקניות שומרים על המנוע הקיים, נעילות, גרסאות, מניעת כפילויות ותגובה אופטימית.
- קוד הכניסה המשפחתי, אם הוגדר ב־TIKO_FAMILY_CODE, מוקלד באתר ונשמר בזיכרון העמוד בלבד; הוא אינו נשמר בכתובת או במאגר הקוד. כשאין קוד, נשמרת הגבלת החשבון הקיימת של גוגל.

## פרסום אוטומטי

Settings → Pages → Source: GitHub Actions.

פעולת pages.yml מריצה בדיקות ובניית אתר. שינויים ב־google/Code.gs, ב־google/Bridge.html או בהגדרות הפריסה מפורסמים לגוגל **לפני** החלפת הממשק בפייג׳ז. הקוד מעדכן את אותה פריסה, שומר על אותו URL, ואינו מוחק את Index או את manifest הפרויקט.

את מזהה פרויקט גוגל שומרים במשתנה ריפו TIKO_GOOGLE_SCRIPT_ID, ולא בקוד הציבורי.

לחיבור החד־פעמי משתמשים ב[הוראות ההתקנה](google-publishing-setup.md) ובכלי scripts/setup-google-publishing.mjs במחשב של בעלת הפרויקט. הכלי מבצע התחברות רשמית לגוגל, בודק גישה לפרויקט ושומר ישירות Repository secret בשם GOOGLE_SCRIPT_OAUTH. אין צורך להעתיק מפתחות. GitHub Actions משתמש בהרשאה רק בענף main; בקשות מיזוג אינן מקבלות אותה. יש להפעיל קודם את Apps Script API בחשבון.

התקנה ראשונית ידנית נתמכת: לאחר פרסום ואימות של אותו קוד גוגל, מפעילים Run workflow עם google_already_deployed=true. אחרי כן שינויים בממשק בלבד מתפרסמים אוטומטית גם ללא סוד OAuth. שינוי עתידי בבקנד נחסם עד שהרשאת גוגל מוגדרת, כדי לא לפרסם ממשק מול שרת שאינו תואם.

## ארכיון שבועי

טריגר ארכיון עצמאי בגוגל טרם הוגדר. הפונקציה archiveCompletedWeekly_ היא פונקציה פרטית ואינה זמינה לבחירה ישירה בעורך הטריגרים; נדרשת הגדרת טריגר נפרדת לפני החלפת אוטומציית הארכיון הקיימת. מבטלים את אוטומציית ChatGPT הישנה רק לאחר אימות הטריגר והרצה מוצלחת.

## כלל הפרסום המשותף

כל push או מיזוג ל־main מפעיל פרסום אוטומטי באותו קישור, ללא תלות בזהות הכותב וללא בקשה מנעה או מהצ׳אט. ההגדרה נשמרת ב־.github/workflows/pages.yml בריפו המשותף. לסביבת github-pages אין Required reviewers ואין Wait timer; מותר לפרסם מ־main. הבדיקות והבנייה עדיין חייבות להצליח. שינויים בקוד Apps Script דורשים את הרשאת GOOGLE_SCRIPT_OAUTH החד־פעמית, שטרם הוגדרה. זמן ההמתנה של פעולת Pages לעדכון תשתית הוגדל כדי למנוע כשל מוקדם כשהפרסום מתעכב אצל GitHub.

## ניקוי שבועי של ״כבר נקנה״

לאחר פרסום קוד גוגל המעודכן, בעלת הפרויקט מריצה פעם אחת בעורך Apps Script את `setupWeeklyShoppingCleanup` ומאשרת הרשאות לטריגר. ההתקנה חוזרת בבטחה ואינה מנקה נתונים בעצמה. הטריגר בודק מדי דקה ומנקה בשבת החל מ־12:00 בשעון Asia/Jerusalem (כולל שעון קיץ). תזמון Google אינו מבטיח ביצוע בשנייה המדויקת; ייתכן עיכוב. אין לבטל את טריגר ארכיון התפריט הקיים.

רק פריטים המסומנים כנקנו לפני מועד האיפוס מוסרים מהרשימה; פריטים שטרם נקנו, מאגר המוצרים והתפריטים נשמרים. קניות שסומנו לאחר 12:00 נשמרות לשבוע הבא גם אם הטריגר התעכב. קריאה או עדכון של רשימת הקניות משלימים ניקוי שהוחמץ תחת אותה נעילה, ומספר הגרסה עולה כשמוסרים פריטים כדי לדחות עדכונים ישנים. רשומות עם תאריך לא תקין נשמרות לבדיקה ידנית.

הפעלה דורשת גם פרסום `google/Code.gs` וגם התקנת הטריגר; שמירת השינוי ב־GitHub לבדה אינה מפעילה אותו בגוגל.
