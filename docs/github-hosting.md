# מעבר מפרסום ב־ChatGPT לפרסום מ־GitHub

## מצב נוכחי

- מקור: `noatiko-sketch/tiko-shabbat-menu`, ענף `main`.
- הקוד באתר הפעיל וב־GitHub הושווה לפני ההתאמה ונמצא זהה, למעט קובץ מטמון טיפוסים.
- לפיני (`pinitiko-coder`) יש הרשאת `write` בריפו.
- גרסת השרת העצמאית משתמשת ב־Next.js ובמשתני סביבה של Node.js. אין בה תלות בשרת Cloudflare במסלולי הייצור.
- פרסום ב־Vercel וחיבור השרת ל־Apps Script עדיין דורשים השלמה. אין לסמן מעבר כמושלם לפני בדיקת API/UI בכתובת החדשה.

## הגדרות Vercel

ייבוא אותו ריפו, Framework: Next.js, ענף ייצור: main, גרסת Node.js: 24.x. קובץ `vercel.json` מגדיר התקנה נעולה, בדיקות ובנייה לפני פרסום. פרסום מענפים אחרים מושבת כדי שלא לחבר גרסאות ניסוי לנתוני המשפחה.

שני משתני שרת נדרשים, בסביבת **Production בלבד**:

| שם | מקור |
| --- | --- |
| `TIKO_BRIDGE_URL` | הכתובת הקיימת של פריסת Google Apps Script, המסתיימת ב־/exec |
| `TIKO_BRIDGE_TOKEN` | המפתח הקיים בהגדרות השרת ובמאפייני Apps Script |

אין לייצר מפתח חדש או לפרסם אותו בקוד. המשתנים מועברים להגדרות האחסון באופן מאובטח בלבד. אין צורך ב־`TIKO_STORAGE`: גרסה זו משתמשת תמיד ב־Drive ואינה פונה ל־D1.

## מה נשאר בגוגל

אותו קובץ state.json, אותו פרויקט Apps Script ואותה פריסה. הקוד לא מריץ מחדש את מעבר D1 ל־Drive. כתובת `/api/drive-migration` החדשה סגורה (410), ופענוח תמונות כבוי (410), ללא שירות בתשלום.

הארכיון נשמר גם בעת קריאת תפריט דרך Apps Script. נוספה פעולת GitHub Actions עצמאית בשם Archive completed Shabbat menus, בכל יום ראשון ב־00:15 UTC (02:15 בחורף או 03:15 בקיץ בישראל). היא פעילה רק לאחר הגדרת משתנה הריפו TIKO_SITE_URL לכתובת האתר החדש, ומוודאת שהתשובה מתייחסת לקובץ Drive המקורי. היא אינה מדפיסה תפריטים או מפתחות. ניתן להריצה ידנית ולוודא הצלחה לפני ביטול אוטומציית ChatGPT הישנה. אין למחוק את האתר הישן או לבטל את התזמון לפני אימות תחליף.

## לפני סיום המעבר

1. לאמת שהבנייה החדשה מצליחה והאתר מקבל כתובת HTTPS.
2. לקרוא תפריט ורשימת קניות ולוודא ש־storage הוא google-drive וש־state_id נשאר מזהה הקובץ המקורי; לא לזרוע נתונים חדשים.
3. לבדוק תצוגת מובייל וטעינת תמונות, תפריט, מאגר מנות ורשימת קניות. בדיקת כתיבה מתבצעת רק עם פעולה הפיכה שמוחזרת למצבה המקורי.
4. להגדיר TIKO_SITE_URL במשתני GitHub Actions, להריץ את Archive completed Shabbat menus ידנית; רק אחרי הרצה מוצלחת לבטל את האוטומציה הישנה.
5. להוכיח פרסום ממיזוג ב־GitHub, כולל שינוי של פיני, בלי פרסום מחשבון נעה בצ׳אט.
6. לעדכן את קישור המשפחה. כתובת chatgpt.site הישנה שייכת לאחסון הישן; הכתובת החדשה תוחזר על ידי Vercel.

## חזרה לאחור

האתר הישן ממשיך לפעול מול אותו קובץ בגוגל. במקרה תקלה משתמשים בו שוב; אין להעתיק נתונים אחורה ממסד אחר. שינוי הקוד ב־GitHub אינו מפרסם לאתר הישן.
