# חיבור חד־פעמי לפרסום אוטומטי בגוגל

תהליך הפרסום בריפו כבר מוכן. נותר לאשר בחשבון גוגל הרשאה מתמשכת לניהול קוד ופריסות Apps Script ולשמור אותה בהגדרות הריפו המשותף. אחרי כן גם שינויים של פיני שנכנסים ל־main יוכלו להתפרסם בלי שנעה תפתח את הצ׳אט או את עורך גוגל.

## 1. הפעלת הגישה בגוגל

בחשבון בעלת הסקריפט, פותחים https://script.google.com/home/usersettings ולוחצים Google Apps Script API. מעבירים את המתג לפעיל. אין צורך להוסיף פרויקט או מסד נתונים.

המתג מאפשר שימוש ב־API רק לאפליקציות שקיבלו בנפרד הרשאה מהחשבון. אישור ההתחברות הוא השלב הבא.

## 2. כלים במחשב Windows

פותחים PowerShell. אם Node.js או GitHub CLI אינם מותקנים, מריצים:

```powershell
winget install --id OpenJS.NodeJS.LTS -e
winget install --id GitHub.cli -e
```

בסיום ההתקנה סוגרים ופותחים מחדש את PowerShell כדי שהפקודות החדשות יהיו זמינות. אם הכלים כבר מותקנים אין צורך להתקין שוב.

## 3. חיבור ושמירה מאובטחת

ב־PowerShell:

```powershell
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/noatiko-sketch/tiko-shabbat-menu/main/scripts/setup-google-publishing.mjs" -OutFile "$env:TEMP\tiko-google-setup.mjs"
node "$env:TEMP\tiko-google-setup.mjs"
```

הכלי משתמש ב־GitHub CLI וב־clasp הרשמי של גוגל. אם צריך, הוא פותח התחברות ל־GitHub; יש לבחור את חשבון הבעלים noatiko-sketch. בהתחברות לגוגל יש לבחור בחשבון שמנהל את פרויקט תפריט השבת.

ההרשאות המבוקשות הן ניהול קוד Apps Script, ניהול פריסות וכתובת האימייל לצורך זיהוי ההתחברות. הרשאות גוגל מסוג זה חלות על פרויקטי Apps Script הנגישים לחשבון; הן אינן מוגבלות טכנית לטיקו בלבד. כלי ההתקנה ותהליך הפרסום בריפו פונים למזהה טיקו שהוגדר, ולא משנים פרויקטים אחרים.

לא מעתיקים שום מפתח לצ׳אט. אחרי אישור ההתחברות הכלי בודק גישה לפרויקט המקורי, שומר את ההרשאה ישירות כסוד מוצפן בשם GOOGLE_SCRIPT_OAUTH באותו ריפו, ומפעיל פרסום מלא לבדיקה. ההרשאה אינה מוצגת במסך או נשמרת בקוד הציבורי. פרופיל ההתחברות המקומי נקרא tiko-github-publishing, בנפרד מפרופילי clasp אחרים.

## 4. בדיקה

פותחים https://github.com/noatiko-sketch/tiko-shabbat-menu/actions ומוודאים שההרצה החדשה של Publish Tiko to Google and GitHub Pages ירוקה, כולל Publish matching Google backend first.

אם מתקבלת שגיאת הרשאה, אין לשלוח קובצי התחברות או מפתחות בצ׳אט. אפשר לשלוח את הודעת השגיאה בלבד. אין לסמן google_already_deployed בבדיקה הזו: המטרה היא לבדוק גם את הפרסום לגוגל.

ההגדרה משותפת לריפו; השותף אינו צריך להתחבר שוב לגוגל. היא ממשיכה לפעול כל עוד הרשאת גוגל תקפה. ביטול הרשאה בחשבון או שינוי מדיניות גוגל עשויים לדרוש התחברות מחדש.
