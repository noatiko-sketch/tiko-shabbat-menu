# אוכל לשבת — משפחת טיקו

תפריט שבת, מאגר מנות, מתכונים ורשימת קניות משותפת בעברית.

## פרסום משותף מ־GitHub

הקוד מוכן לפרסום ב־Vercel כיישום Next.js רגיל, ללא ChatGPT Sites או Cloudflare. חיבור האחסון והבדיקה באתר החדש עדיין נדרשים; האתר הפעיל הקודם נשאר זמין בזמן המעבר.

1. כל אחד עובד בענף משלו ופותח Pull Request ל־`main`.
2. בדיקת `Check` מריצה טיפוסים, 113 בדיקות ובניית אתר.
3. אחרי חיבור הפרויקט ל־Vercel, מיזוג ל־`main` מפרסם אוטומטית. אין צורך לבקש פרסום בצ׳אט.

[מצב המעבר והגדרות האחסון](docs/github-hosting.md).

## הנתונים בגוגל

כל המידע המשפחתי נשאר בקובץ Google Drive המקורי, דרך אותה פריסת Apps Script. אין להעתיק את הנתונים ל־GitHub או ליצור מאגר חדש.

מגדירים **בשרת האחסון בלבד** את `TIKO_BRIDGE_URL` ואת `TIKO_BRIDGE_TOKEN` הקיימים. אין להכניס מפתח לקוד, לצ׳אט, ל־Pull Request או למשתנה שמתחיל ב־`NEXT_PUBLIC_`. אם החיבור חסר או תקול האתר מחזיר שגיאה; אין מעבר למאגר חלופי.

אין צורך לשנות את Apps Script עבור המעבר הזה. שינוי עתידי במנוע הנתונים מחייב בנייה ופרסום של `google/Code.gs` התואם.

## פיתוח ובדיקות

נדרש Node.js 24 ו־pnpm בגרסה הרשומה ב־package.json.

```sh
pnpm install --frozen-lockfile
npm run check
npm run build
npm run dev
```

הבדיקות משתמשות בנתונים מבודדים ואינן נוגעות ב־Drive המשפחתי. פיתוח מול הנתונים האמיתיים דורש את הגדרות השרת המקומיות בקובץ סביבת עבודה שאינו נכלל ב־Git.

פקודות `dev:sites` ו־`build:sites` נשארות לצורכי השוואה בלבד; הן אינן מסלול הפרסום החדש.
